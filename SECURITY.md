# Security

Report vulnerabilities privately through the repository owner's preferred private channel rather than a public issue.

Research-data rules:

- Treat uploaded videos, NPZ files, JSON, model weights, and generated reports as untrusted.
- Do not commit credentials, private routes, participant data, raw recordings, or model-weight files.
- The local UI is not an authenticated hosted service.
- Any future hosted deployment requires authentication, authorization, quotas, isolation, retention controls, and redacted errors before public use.
